## `> whoami`

```bash
$ cat /dev/ultrapdf
Nome:   UltraPDF
Preço:  grátis
Foco:   edição · assinatura · anotações · organização de PDFs
Modo:   PWA instalável · offline · sem cadastro
```

O UltraPDF é um editor de PDF gratuito que funciona no navegador e pode ser instalado como aplicativo. Edite textos, assine documentos, faça anotações, oculte informações sensíveis e organize páginas. O processamento acontece no seu dispositivo: seus arquivos não são enviados para um servidor.

---

## `> ls ./recursos`

| Recurso | Detalhes |
|---------|----------|
| ✏️ **Editar texto** | Atualize textos existentes e ajuste fonte e cor, preservando o fundo original |
| ✍️ **Assinar e anotar** | Desenhe assinaturas, destaque trechos, faça marcações e aplique carimbos |
| 🛡️ **Ocultar informações** | Oculte dados sensíveis diretamente no documento |
| 🖼️ **Inserir imagens** | Adicione imagens aos seus PDFs |
| 📄 **Organizar páginas** | Reordene, gire, duplique ou extraia páginas individuais |
| 🔗 **Mesclar PDFs** | Junte páginas e documentos em um único arquivo |
| 📱 **PWA instalável** | Instale no computador ou celular e use os recursos offline |

## `> cat ./privacidade`

```json
{
  "cadastro": false,
  "preço": "gratuito",
  "processamento": "no seu dispositivo",
  "envio_de_arquivos": false,
  "offline": true,
  "armazenamento_local": "IndexedDB",
  "rastreamento": false
}
```

- **Sem cadastro** — abra o UltraPDF e comece a usar.
- **Seus arquivos ficam no dispositivo** — o processamento acontece localmente, sem upload para servidores.
- **Funciona offline** — o UltraPDF é um PWA preparado para uso offline.
- **Documentos salvos localmente** — os documentos offline ficam no armazenamento do navegador, via IndexedDB.

> [!NOTE]
> O navegador pode apagar dados locais se você limpar os dados do site. Mantenha uma cópia dos arquivos importantes no seu dispositivo.

## `> ./iniciar`

```bash
1. Acesse   ultrapdf.github.io
2. Abra     selecione um PDF do seu dispositivo ou use um exemplo
3. Edite    faça alterações, assine, anote ou organize páginas
4. Instale  use o menu do navegador → "Instalar aplicativo" (opcional)
```
